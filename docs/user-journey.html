How to read this: stage codes (enquiry → offer_otp → bond_application → bond_granted → documents_fica → clearance → lodgement → registered) are the live statuses in the Sold Direct deal tracker — every change is time-stamped, audited, and mirrored to both parties on WhatsApp. Message previews are the actual templates sent by the platform. Durations are typical for Western Cape transfers; either party can reply in the chat at any stage and a human concierge steps in. Cancellation is possible from any stage before registration. All personal data is processed under POPIA with explicit consent captured before anything is collected or shared.
